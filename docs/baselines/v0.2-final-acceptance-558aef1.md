## 证据分层（ADR-0013 §2）

1. **计数权威 = CI 常驻测试**：冻结阈值的多 Work Item 行在 `tests/v02-final-acceptance.test.ts` 逐条断言并全绿——Local Git 冷轮 executions ≤5、热轮增量 =0、恒等式 `logical = hits + joins + executions + failures`；GitHub REST 冷轮 upstream ≤2、热轮增量 =0；Remote Git 两轮 upstream =0。失败时输出三平面完整原始指标。CI `verify` 于 head `558aef1` 全绿（含 typecheck/build/test/coverage/lint/六静态门禁）。
2. **实测描述层 = 冻结脚本原样重跑**（本文件）：以 `CLICKVIBE_ACCESS_BASELINE_SHA=558aef1…` 在最终 head 原样执行六场景，证明冻结复现器与哈希守卫在终态代码上仍然成立，并保留全部原始输出。

**已知 harness 限制（声明）**：冻结脚本的场景调用不注入 `observation`（其场景形状早于 #122 的注入参数），因此 `enrichWorkflowStates` 走 `sampleWorktreeFactsLegacy` 缺省逐事实采样路径，而非生产 `/state` 的快照 registry 路径。这正是 #122 保留该等价基线的原因。因此脚本中的本地 Git 子进程计数反映 fallback 路径，**计数结论以上述 CI harness 为权威**；本层只作可复现性与原始证据。
