# 历史实施计划

> Status: Historical

本目录保存带日期的调研、设计和实施记录，用于解释某次改动当时的上下文与证据。它们不是当前架构或产品路线的事实源，也不要求在后续决策变化时逐篇重写。

当前有效入口：

- [当前有效架构](../architecture.md)：系统边界、事实所有者和生效规则。
- [产品演进路线](../roadmap.md)：版本顺序、用户结果和退出标准。
- [架构决策记录](../architecture/decisions/README.md)：长期取舍及其 Accepted/Superseded 状态。

历史文档若包含会直接误导当前施工的旧规则，应在顶部增加醒目的 superseded 说明并链接替代决策；普通历史事实保持原样。临时评审稿、排序提案和重复蓝本在结论吸收进权威文档后删除，不把同一当前规则维护在多处。
